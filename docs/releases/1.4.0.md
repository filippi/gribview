# Gribview 1.4.0

This release focuses on installation and reliable startup.

- **macOS:** Apple Silicon only, macOS 15+. Open the DMG and drag Gribview into Applications. Libraries, ecCodes data, font and icon are included. The unsigned build requires Privacy & Security > Open Anyway on first launch.
- **Linux:** x86_64 AppImage, portable tarball and Debian package. Tested on Ubuntu 22.04, Ubuntu 24.04 and Debian 12. Portable packages include the application libraries and ecCodes data; a graphical desktop and OpenGL 3.2 are required.
- **Homebrew:** updated source formula with decoding tests, ARM64 bottle automation, and a separate `gribview-app` cask.
- **Python:** native wheels for macOS ARM64 and Linux x86_64, installable without compiling or downloading dependencies at first launch.
- **Windows:** ZIP with the executable and runtime DLLs.
- **Diagnostics:** `--version`, `--diagnostics` and `--check FILE`; startup errors are visible and return failure codes.
- **Appearance:** the same bundled font and icon are used regardless of the launch directory. The About window includes build identification.

The Linux tarball includes `install.sh` to add Gribview to the current user's applications menu without administrator access. The AppImage is also tested after extraction, without requiring FUSE in a container.

macOS Intel/universal builds are intentionally not included. The macOS download is unsigned because a Developer ID signing identity has not been configured.

Downloads and installation instructions: https://filippi.github.io/gribview/
